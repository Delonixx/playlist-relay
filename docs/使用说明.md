# 歌单接力 · v0.7.0 Beta

把 ChatGPT 歌曲列表变成自己的网易云或 QQ 音乐歌单。支持搜索、人工核对发行版本、只追加和读回核验；也能读取已有歌单，生成风格图、乐评和可继续匹配的推荐。

新增 **Spotify / Apple Music 官方接入代码**，配置、授权、搜索、候选核对和已有歌单追加流程已实现。两个新平台尚未用真实账号完成授权和写入验收；需要用户自己的开发应用 / 签名配置。Spotify 平台内容不用于 AI。详见 [全球平台接入.md](../全球平台接入.md)。

2026-10-11 用户确认：网易云、QQ 音乐已实测可用。网易云使用固定依赖；QQ 使用独立 Web 适配器，默认手机 QQ / 微信扫码。用户确认不代表所有账号、扫码方式或权限组合均已验收；这两个平台使用非官方接口，兼容情况可能变化。QQ 的配置、能力边界和协议来源见 [QQ接入.md](../QQ接入.md)，原始调研保留在 [调研与方案.md](../调研与方案.md)。

## 打开

需要 [Node.js](https://nodejs.org/) 22 或更新版本。

- **只看界面**：双击 `预览新版.cmd`，离线演示端口 8772。不需要音乐接口依赖、登录或 AI Key。
- **正式使用**：首次安装下面的依赖，再双击 `start.cmd`，默认端口 8765。
- 从窗口复制“请打开”后的完整地址，包括 `#` 后的本次访问令牌。只打开裸地址无法操作。完整地址可刷新；重启服务要复制新地址。
- 停止服务：在启动窗口按 Ctrl+C。升级后请停止旧服务再启动，避免新前端与旧后端混用。

首次正式安装，在项目目录的终端执行：

```powershell
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile --ignore-scripts --registry=https://registry.npmjs.org
node server.mjs
```

已有 pnpm 可跳过第一步。源码包不包含 `node_modules`，也不是独立 exe。接口依赖固定为 `@neteasecloudmusicapienhanced/api@4.41.1`，锁文件固定间接依赖；不要改成 latest 后沿用旧验证结论。

端口冲突可在启动前设置 `$env:PORT = '8766'`。离线演示也可运行 `node server.mjs --demo` 或 `demo.cmd`。所有演示歌曲、图表与导入结果均标记为模拟数据，不接收凭证。

## v0.7.0 接入改动

Spotify 使用官方 PKCE，无需 Secret；Apple Music 使用独立 MusicKit 授权页，可在本机签名。配置错误不会阻止其他平台启动。新增权限、地区、分页、跨类型 ID 核对和 Apple 延迟读回检查，写入仍不自动重试；保留 v0.6.3 的扫码继续选择、空状态引导与口味反馈。

## v0.6.3 体验改动

未登录时可以从歌单选择入口扫码，连接成功后继续选择；取消不继续。分析入口会根据当前状态引导添加歌曲或配置 AI。修改来源时，图表前显示旧结果说明。QQ 的已匹配专辑封面可显示，深色图表说明与手机点击区域也已调整。

## 歌曲导入

1. 在导航中的“音乐平台”选择网易云或 QQ。网易云可用 App 扫码并确认，再点“检查扫码状态”，至少间隔 3 秒；QQ 默认用手机 QQ / 微信扫码并在手机确认，自动检测连接；Cookie 仅作备用。
2. 选择自己创建的歌单，或填当前平台完整歌单链接 / 数字 ID。网易云可新建私密歌单；QQ 创建接口未确认支持私密，默认禁止创建，需明确选择公开才能执行。也可在官方客户端新建私密歌单，再填写链接。首次建议用专用测试歌单导入 3–5 首。
3. 在歌曲列表粘贴每行一首的 `歌名 — 歌手`，选择输入顺序，搜索并匹配。
4. 核对歌名、歌手、专辑和录音版本。“换版本”可选其他候选；不确定的歌跳过。匹配分是排序依据，不是准确率，多发行版本不会盲选。
5. 点击“核对并导入”，确认目标和数量后追加。完成后下载核对记录，在官方客户端确认新增和版本。

```text
That's Enough for Me — Patti Austin
If I Ain't Got You — Alicia Keys
So Sick — Ne-Yo
```

支持 Markdown 编号、加粗、Tab、竖线和带空格的破折号，`Ne-Yo` 不会被拆开。只有歌名可以搜索但不预选。输入最多 200 首。不支持图片 OCR、Excel 或完整 CSV 引号语法；不要粘贴整段乐评。

切换平台会清掉旧目标、匹配和分析来源。通常保留输入文字，离开 Spotify 时同时清除文字，避免平台资料进入 AI。不同平台的 Cookie / 令牌分开保存在进程内存，不相互传递；AI Key 独立保留。每个页面随请求附上平台标记，旧页面发现平台已切换会拒绝继续操作，防止 ID 混用。

| 硅基流动 | Qwen/Qwen3-8B | 同时提供免费和收费模型，模型可用性与价格以账号控制台为准。[接口说明](https://docs.siliconflow.cn/docs/api/chat-completions-post) |

默认智谱免费模型无需费用勾选；其他配置必须明确勾选费用说明才能保存。不会自动换服务、换模型或重试。表中的模型是预填配置，不是对每个账号均可调用的承诺；本版尚未用真实 Key 验证这些模型。国内访问仍取决于本机网络与账号权限。

各服务 Key 单独保存在本机 Node 进程内存，保存后输入框清空。切换服务时不会传递另一家 Key；同一服务留空可复用本次会话已有 Key。不写入文件或浏览器存储；可清除所选或全部 Key，停止服务也会清除。模型分析只向当前选定服务发送歌曲资料、推荐偏好及主动标记的歌曲反馈，不发送音乐平台 Cookie、账号身份或歌单链接。切换或清除凭证会取消旧任务并清除旧分析结果。

1. “分析”的来源卡片显示实际歌单名、已读取数量和本次最多分析数量。点“查看歌曲”核对已取得的歌曲资料。读取仅取资料，追加操作的结果在歌单页单独显示。
2. 来源下拉框显示具体歌单名和数量；切换目标但还没读取时明确提示旧来源。来源缓存只保存在本机进程内，页面刷新可恢复，停止服务或更换登录后清除。
3. “分析”选择认真乐评 / 直白锐评和分析范围。默认分析全部已读取曲目，最多 200 首；可改为最多 100 首或快速 40 首。超出所选范围时均匀抽样。修改来源、范围或点评后，旧分析显示更新提示。喜欢或避开的元素统一在“发现”的“推荐偏好”填写，仅用于选曲，不改变原歌单评分；清空表示取消该偏好。
4. 六维图展示律动、能量、人声、器乐、氛围和跨度。点击维度，显示整体分数、计算依据、低 / 高分端定义，以及代表曲目的单曲分数、置信度和逐维理由。器乐表示声部参与表达及独立展开，包含电子乐器，修正了旧版“原声器乐倾向”的含义。整体低分时优先展示接近整体分的曲目，并提供有差异的对照；缺少理由时明确标注，不拿通用介绍补充。整体分数不等于每首参考歌曲都得同一个分数。
5. “发现”点单首的“查找封面 / 版本”，或“自动选择封面”逐首查询。只展示真实曲库候选封面；未取得封面时保留原创占位。默认在歌名、歌手、录音标记一致的匹配候选中按收藏数选择；不会自动拿翻唱 / Live 替换原作。QQ 的 `240w+` 等是平台显示量级，按量级优先，不能称为精确人数或全曲库最高。并列保留待确认；没有收藏数据时标注未知，保留原匹配结果。网易云当前没有歌曲收藏人数数据。换版本后显示“已选版本”，歌名、专辑和封面一起更新。
6. 勾选推荐后“匹配所选歌曲”。已选版本会带入新匹配预览；若该版本已不在候选中则留空提示，不能自动替换成别的录音。最后仍需核对并确认导入。封面查询本身不追加歌曲。

推荐方向位于“发现”：贴近口味保留唱法 / 编排 / 律动；向外延伸改变流派分支、年代、地区或编排；尝试跨界要求模型跨到不同流派家族。改方向或偏好后，点击“生成推荐”；未改设置时为“换一批”。每次请求新候选，去重后每批最多显示 12 首；“本批 N 首”不是全部可推荐曲目的总量。候选先完整检查再截取，排除已读取原曲目及最近 60 条推荐，校验歌名、歌手、理由和实际来源引用。方向标签、连接和差异属于可选说明，缺少时不误拒整首歌。模型对作品和流派仍可能判断错误，筛选不等于真实听感保证。

换推荐只复用已完成画像、发送一次请求，不重新打分或重读歌单。请求使用专门的推荐格式，建议模型提供 16–24 个候选以便筛选；不确定时可以少返回，不编造曲目。即使当前输入已清空，也可以使用明确标明名称的上一份画像生成推荐。全部重复或缺少必需资料时，提示返回数量及各拒绝原因，保留上一批并显示“再生成一次”，不自动重试。离线模式的示例池有限，展示完会明确说是演示歌曲用尽，不把它当真实曲库耗尽。单首封面失败显示在对应卡片，其余继续查询，可单独重试。

收藏优先仍作为后台的默认版本选择规则，卡片不再展示“按收藏数优先”等实现说明。需要手动换版本时，专辑候选中保留平台可用的收藏量，供用户比较。

歌曲追加后，已读取的来源会提示资料是追加前的快照；重新读取才能更新数量和分析。工具不会假定追加成功就把旧元数据拼成新歌单。

**图表基于歌曲资料与模型已有知识估计，没有读取或播放音频，也不是对人的品味打分。** 未识别作品保留未知值；资料不足时不画完整填充多边形。前五维取可识别作品的置信度加权平均；跨度依据模型估计的流派分布计算归一化熵。每条点评引用限定为实际输入中的歌曲。

## 待选与口味记录

- 卡片勾选表示准备核对导入，和“喜欢”分开。换一批不会丢失待选歌曲；页面底部可以查看、移除或把不同批次一起带入匹配，最多 200 首。选好的专辑版本一起传递；版本不再可用时仍需重新核对。待选仅保留在当前页面，刷新 / 关闭页面或切换音乐平台会清空。
- “喜欢”提供正向作品参考；“少推荐”减少类似听感，同时从待选中移除该曲；“听过”只避免再次推荐这首，不当作负向喜好。三种标记互斥，再点同一标记可撤销。“口味记录”可以查看、撤销或确认清除全部。
- 最多 200 条反馈只保存歌名、歌手、标记，使用此浏览器的 localStorage；不保存 Key、Cookie、账号、歌单链接或访问令牌。刷新、重启本地服务后，同一浏览器和端口可恢复记录。换浏览器、端口或清除站点数据不会迁移；演示和正式记录分开。浏览器禁止保存时退化到本页内存，并在记录窗口说明。
- 标记本身不会调用 AI，也不改变原画像。下次点击生成或分析时，反馈发送给所选服务：已标记曲目从候选中排除，喜欢和少推荐作为选曲参考。此功能是提示上下文，不是训练个人模型，也不保证模型一定理解听感。清除记录影响后续请求，已经发送的请求无法撤回。
- 若升级文件但旧 Node 服务仍在运行，新页面会识别尚未支持反馈的后端，禁用标记并说明原因，不假装已生效。旧登录会话不会被自动停止。

本轮产品自查原则见 [体验迭代Prompt.md](../体验迭代Prompt.md)，改动与验收见 [迭代记录.md](../迭代记录.md) 和 [验证记录.md](../验证记录.md)。

读取歌单最多取 200 首资料，大歌单均匀抽样；默认不再从中压缩成 40 首。超过 32 首时按每批最多 32 首串行判断，再单独汇总点评。例如 77 首需要 3 批判断 + 1 次汇总，200 首需要 7 批 + 1 次汇总。页面显示预计调用次数和进度；更多歌曲消耗更多额度，收费服务按实际调用计费。可停止任务，完成的画像保留。模型错误立即停止；显式重新分析相同来源 / 配置时，可复用本次进程内已完成的批次。缓存不写文件，重启或切换配置会清除。

页面显示总数、分析数量和抽样状态。结论只代表实际分析范围，200 首以上歌单或快速分析仍可能遗漏少见风格。未知曲目不捏造分数。旧版结果缺少新字段及新评分含义，升级后需重新分析一次，才能看到逐维理由；可导出分析 JSON。

## 网易云扫码与 8821

本版将二维码握手切到固定上游版本默认的 EAPI 协议，保留握手 Cookie 与稳定设备标识。已能使用的手动 Cookie 路径继续走 WEAPI。

扫码授权和账号资料验证是两个阶段。如果扫码为 803，而账号接口随后返回 8821，工具保留已授权会话并显示资料验证失败。可在官方客户端检查后点“验证已授权会话”，不用反复生成二维码。**仅凭 8821 不能确定平台拒绝的原因；这些修正不能保证所有账号都可登录或免于风控。**

扫码失败可在本地用自己在 [网易云官网](https://music.163.com/) 已登录的 Cookie：F12 → Network → 刷新 → 选择已登录请求 → Request Headers → Cookie，确认含 `MUSIC_U`，粘贴到工具的 Cookie 页验证。不要把 Cookie 发到聊天、issue、在线 API 或公开截图。输入框提交后清空；失败的替换恢复此前工具会话。

Cookie 仅在内存。“清除登录”只清除工具会话，不会注销官方客户端。用完关闭服务，按需自行清空剪贴板。浏览器和操作系统的剪贴板历史、内存交换、崩溃转储不在工具控制范围内。

## 歌单链接

正式导入后显示已有目标的链接：网易云为 `https://music.163.com/playlist?id=真实ID`，QQ 为 `https://y.qq.com/n/ryqq/playlist/真实ID`，Spotify 为 `https://open.spotify.com/playlist/真实ID`。Apple 首版只给官方资料库入口，不把资料库 ID 冒充公开分享链接。链接指向已有内容，不能凭空把文字编码成平台歌单。

QQ 短链接暂不展开，请从官方页面复制完整歌单链接。也可导出确认文字供官方文字导入功能使用；官方跨平台链接导入入口的兼容性仍需自行核实。

## 数据与失败处理

- 服务只绑定 `127.0.0.1`，校验 Host、Origin 和启动令牌；Spotify 回调另验一次性 state。没有跨域开放、任意 API 地址、远程代理或统计服务。主界面代码和字体不依赖外部 CDN，只有独立 Apple 授权页加载官方 MusicKit 脚本；歌曲封面按需从受限平台图片域名读取，不打包图片。
- 网易云只复用固定依赖的加密函数，限定原有 9 个白名单；QQ 限定 9 个 RPC，音乐请求固定 `u.y.qq.com`；扫码仅访问限定的 QQ / 微信官方授权地址。不启动上游通用服务。搜索和收藏量查询不携带账号 Cookie。
- 音乐操作串行限速。每批最多追加 10 首，等待后读回验证；网易云 / QQ / Spotify 只追加自己创建的歌单，Apple 只追加明确可编辑的资料库歌单，不删除、覆盖或重排。
- 跳过已有 ID；超时、拒绝、部分接受或读回缺失停止，不自动重试写入。Apple 更新延迟时只做有限次数的只读核验。报告 `unverified` 包含未确认和未尝试的剩余 ID，不表示全部确定失败。
- 失败的请求可能已在平台生效。先看官方歌单，再重新匹配；新导入重新读取已有 ID。非官方接口变更和账号风控仍可能导致不可用。
- 下载记录可能透露个人歌单信息，请自行保管。工具不自动回滚；加错版本时只在官方客户端撤销记录中确认新增的曲目。
